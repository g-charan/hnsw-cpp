What is actually happening

The graph, the vectors and the beam search are the same C++ that the command line tool uses; only the entry points differ. The index was built offline and is fetched here as one 6.3 MB buffer, which the search reads in place. Building an index is a minutes-long job and is deliberately not compiled in. Source on GitHub.
